# 微信公众号 / 视频号 / 抖音 / 快手 / 小红书 / 哔哩哔哩 下载与转码工具箱

一个本地运行的一站式多平台内容下载与管理工具，支持微信公众号、视频号、抖音、快手、小红书、哔哩哔哩资源离线下载、RSS 订阅及视频转码。

支持桌面应用原生窗口（`pywebview`）运行，也可作为 Web 服务在浏览器中访问。

> [!TIP]
> **开箱即用，无需配置本地 Python 开发环境！**
> 本项目已通过 GitHub Actions 自动构建 Windows 与 macOS 双平台客户端。请直接前往 [👉 GitHub Releases 下载最新版本 (v2.1.0)](https://github.com/x554960766/wechat-mp-tools/releases)。

### macOS 版本选择

| Mac 类型 | 下载版本 |
|----------|----------|
| **Apple Silicon**（M1/M2/M3/M4 芯片） | `ARM64` 系列产物 |
| **Intel** 芯片 | `x86-64` 系列产物 |

如果不确定自己的芯片类型，点击屏幕左上角  &#x1F5A5;  →「关于本机」即可查看。ARM64 产物无法在 Intel Mac 上运行，x86-64 产物虽然可以通过 Rosetta 在 Apple Silicon 上运行，但推荐使用原生 ARM64 版本以获得最佳性能。

## 核心功能

### 📱 微信公众号
- **多格式离线导出**：支持完整保存原文排版的 HTML、保留语义结构与代码高亮的 Markdown，以及高精度矢量 PDF 导出。
- **智能采集与批量下载**：粘贴单篇文章链接即可自动解析并添加公众号，支持按时间范围或指定篇数批量下载历史文章，支持断点续传与自动去重。
- **RSS 订阅与增量同步**：内置标准 RSS 2.0 服务，为每个公众号生成独立 Feed 订阅链接，支持各类阅读器订阅及定时后台增量更新。

---

### 🎥 微信视频号
- **单视频解析下载**：粘贴分享链接即可快速解析并无水印下载视频。
- **博主作品采集**：支持收藏博主、获取作者主页作品列表，支持一键批量下载。
- **关注列表一键增量采集**：一键同步并增量采集所有已关注博主的作品，自动跳过已下载内容。
- **本地历史自动同步**：自动扫描本地已下载文件，智能补全下载历史记录。

### 🎵 抖音（v2.0.8 评论深度抓取/收藏作者全新主页与风控自愈升级）
- **单视频与图集无水印解析**：支持单条视频与图集内容一键无水印下载，提供直链提取、新标签页播放与文案一键复制。
- **视频评论抓取与结构化导出**：
  - 支持单视频评论全量/限量抓取，完整保留一级主评与二级楼中楼回复（评论内容、点赞数、发布时间、用户信息等），导出为标准化 JSON。
  - **智能评论下载设置弹窗**：支持预设胶囊快速点选（50条 / 100条推荐 / 300条 / 500条 / 全部评论），支持自由输入任意下载条数、灵活控制是否包含楼中楼回复，并支持记忆默认偏好。
  - **评论与视频同目录协同归档**：评论文件自动与对应视频存放在创作者同名目录下，并在「下载记录」中以作者为维度合并折叠展示。
- **用户主页内置「已收藏作者」精选微卡片**：
  - 用户主页（`#dy_user`）未选择作者时直接展示已收藏创作者微卡片，像素级适配微信视频号高质感风格并微缩优化。
  - 自动自适应明暗主题文字对比度（在白底/暗底均清晰醒目），支持一键点击进入主页、双向无缝流转及快捷取消收藏。
  - 「搜索用户」结果卡片直接支持添加收藏并与主页双向实时状态联动。
- **喜欢/点赞列表智能穿透**：
  - 支持查看与批量下载当前登录账号的点赞视频，即使喜欢列表设置为「仅自己可见（私密）」亦可无感获取。
  - 支持输入任意公开博主的 `sec_uid` 或主页链接，一键获取他人公开点赞列表。
  - 支持物理滚动无限翻页采集与本地增量去重。
- **全能收藏体系 (`collect` & `collectmix`)**：
  - **全部收藏单视频**：直接拉取个人全部收藏视频列表。
  - **分类收藏夹**：支持获取自定义收藏夹分类列表及每个收藏夹下的专属视频。
  - **收藏合集列表**：支持获取已收藏的合集/播单列表（`collectmix`）。
- **双通道风控自愈与 msToken 升级**：
  - 针对抖音 `ArgusSecurityPlugin` 动态 `uifid` 与 `x-secsdk` 风控拦截，实现「HTTP 直连 + Playwright 会话沙箱」自动容灾自愈降级，100% 稳定穿透。
  - 扫码登录自动初始化个人主页与收藏会话，全自动提取与同步新鲜安全凭证。
  - 参考 upstream 最新规范重构 msToken 生成算法及合集双来源聚合逻辑。
- **直播间与回放解析**：支持抖音直播间实时解析（状态、清晰度列表、主播信息）以及博主历史直播回放列表采集。
- **搜索博主信息增强**：多线程并发补全搜索结果中的博主作品数、粉丝数与获赞数据。
- **下载记录清理优化**：彻底清理历史中的无效批量记录，新增下载记录单条快捷删除功能。

### ⚡ 快手
- **高清视频解析下载**：支持快手单视频、图集无水印解析与批量采集。
- **流式断点续传与重试自愈**：支持网络异常中断自动重试与 Range 断点续传，保障大文件下载稳定可靠。

### 📕 小红书
- **单篇笔记解析**：支持粘贴小红书图文/视频链接，无水印下载高清图片、视频及 Live 实况图，导出文案文本与离线网页。
- **智能视频流挑选与容灾**：自动优先挑选通用兼容性最佳的 H.264 编码最高清视频轨，支持多候选 CDN 自动重试降级下载。
- **博主主页深度采集**：支持 SSR 状态与页面 DOM 智能混合提取首屏笔记，配合网络接口拦截与物理滚动，完整采集博主所有笔记作品。

### 📺 哔哩哔哩
- **单视频与多分P下载**：支持 BV/AV 号、番剧及多分P视频解析，批量下载指定分P。
- **UP主空间投稿采集**：收藏 UP 主或输入空间链接，一键获取投稿列表并批量下载。
- **音视频无损混流**：自动下载最高清画质音视频轨，并使用本地 FFmpeg 自动混流为完整 MP4。
- **弹幕与字幕提取**：支持将弹幕转为 ASS 格式，支持提取 CC 字幕并转为 SRT/ASS 格式。

### 🎬 视频转码与空间优化
- **全格式兼容**：支持 MP4、MKV、MOV、WebM、AVI、FLV、TS 等视频格式互转，以及提取 MP3 音频。
- **一键智能扫描**：自动递归扫描微信视频号与抖音所有已下载媒体，支持一键批量转码与拖拽导入。
- **硬件加速与压缩比对**：支持 H.264/H.265 编码与硬件加速，实时计算转码前后体积比对与空间节省百分比。
- **环境自愈**：自动探测加载系统与内置 FFmpeg 环境，缺失时支持一键自动下载配置。

## 微信公众号使用指引

1. **添加公众号**：复制任意一篇公众号文章链接，在「公众号」页面粘贴并点击添加，自动获取公众号信息建档；
2. **文章导出**：支持单篇直接输入链接下载，或在公众号详情页按时间范围/篇数批量拉取，导出 HTML、Markdown、PDF 格式；
3. **RSS 订阅**：在公众号详情页点击「RSS」获取订阅链接，可直接添加至各类 RSS 阅读器。

## 本地运行与二次开发

如果你需要直接运行源码或进行二次开发：

```bash
# 1. 克隆代码
git clone https://github.com/x554960766/wechat-mp-tools.git
cd wechat-mp-tools

# 2. 安装依赖
pip install -r requirements.txt
playwright install chromium

# 3. 启动应用
python main.py   # 桌面端模式（基于 pywebview 原生窗口）
# 或
python app.py    # 浏览器模式（访问 http://localhost:5200）
```
