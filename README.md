# 微信公众号 / 视频号 / 抖音 / 快手 / 小红书 / 哔哩哔哩 下载与转码工具箱

一款功能强大的全能多平台内容下载、归档备份与 RSS 订阅工具箱。支持 Windows / macOS 客户端桌面开箱即用，同时支持 Docker 容器化服务端部署。

> [!TIP]
> **桌面端开箱即用，无需配置 Python 开发环境！**
> 本项目已通过 GitHub Actions 自动构建 Windows 与 macOS 双平台客户端。可直接前往 [👉 GitHub Releases 下载最新客户端](https://github.com/x554960766/wechat-mp-tools/releases)。

## 🌟 核心功能特性

### 📱 微信公众号

> [!IMPORTANT]
> **💡 降低风控核心建议：强烈建议在「账号池」中添加 2~3 个账号！**
> - **为什么需要账号池**：微信读书对单一账号的高频连续请求有较严格的瞬时频控（`-2014`）与安全验证（`-2041`）策略。单账号在连续下载几十或上百篇推文时容易受到限制。
> - **如何配置**：前往左侧导航栏的 **「账号池」** 页面，使用手机微信扫码添加 2~3 个微信读书账号（如个人小号或备用号）。
> - **自动防护机制**：系统内置了账号池轮换调度器，在拉取文章列表、批量下载以及 RSS 定时更新时，会自动在活跃账号间平摊并发；当某个账号遭遇频控或需验证时，会自动平滑切换到备用账号无感续跑，最大化降低封控风险。

- **多账号池与智能负载均衡（降低风控关键）**：支持扫码维护多账号池，自动轮换借出可用会话、动态分配请求，并自带账号级频控冷却与会话健康监测。单账号受限时自动平滑切换备用账号无感续跑，最大化平摊调用频率、规避封控。
- **一键极速采集与增量去重**：支持一键采集单号最新 50 篇推文，或一键串行采集全部关注公众号（各 50 篇），内置本地已下载排重与账号轮换，极大优化风控。
- **历史文章全量采集**：完整获取公众号历史文章列表，支持按时间范围与篇数批量拉取。
- **文章列表精准展示**：推文发布时间精确到分钟（`YYYY-MM-DD HH:mm`）；严格识别微信官方版权属性，精准展示「原创」徽章。
- **高保真多格式导出**：
  - **离线 HTML**：图片、音视频等外部资源本地化保存，离线排版与原文完全一致。
  - **语义 Markdown**：完美适配 Obsidian、Notion 等知识管理软件。
  - **矢量 PDF**：支持一键导出高质量 A4 矢量排版 PDF 文档。
- **智能内容清洗过滤**：自动识别并剔除小节标题横幅图、二维码、广告区及引导关注短文本，支持规则自定义及对已下载存量文章一键重跑清洗。
- **高性能标准 RSS 2.0 订阅**：
  - 为每个公众号生成独立专属 Feed，支持全聚合 Feed。
  - 支持后台定时增量抓取、全文/摘要输出模式、访问令牌（Token）鉴权与 ETag 缓存机制。
- **智能风控防护与错误码自愈**：深度适配上游网关策略，内置人机验证与瞬时频控（-2014）自动退避重试、网关超时（-2012）自动重放与会话休眠（-2041）自愈通道，遭遇风控时自动冷却防封并联动网页滑块验证，全链路保障账号安全。
- **数据库多引擎支持**：默认内置零配置 SQLite（`data/wechat_tools.db`），支持一键无缝配置远程 MySQL 存储，且自带平滑容灾回退能力。

#### 🛡️ 微信公众号防风控与日常使用最佳实践

1. **常驻 2~3 个账号进「账号池」**：
   微信读书接口以用户会话为单位进行频控计量。配置多账号后，系统在下载文章、拉取列表及 RSS 定时抓取时会自动均匀分散流量，大幅提升大批量下载的成功率。
2. **优先使用「一键增量采集」**：
   日常归档建议点击「采集最新50篇」或「全部关注公众号一键采集」，系统已内置本地已下载比对逻辑，自动跳过存量文章，仅下载最新发布内容，避免全量无谓扫描。
3. **保持合理的请求间隔**：
   系统默认配置了 1.0 ~ 1.5 秒的安全随机请求间隔。如需调整，请在「系统设置」中保持在 0.8 秒以上，避免因请求频率过密触发腾讯防水墙拦截。
4. **安全验证（防水墙）自愈恢复**：
   若连续密集采集触发了腾讯滑块验证（错误码 `-2041`），无需惊慌：直接在客户端/Web 弹出的滑块窗口完成拼图验证，或者在手机微信读书 App 中打开任意书籍阅读片刻，系统便会感知会话在线态并自动自愈恢复。

## 🐳 Docker 部署（服务端 / NAS / VPS）

本项目全面支持容器化部署，提供轻量版（专注公众号 + RSS）与全功能版两种运行形态。

### 1. ⚡ 一键极速部署（推荐）

#### 方式 A：Docker CLI 一行命令启动（开箱即用）
无需先配置复杂的环境或目录，只需执行一行命令即可在后台启动：
```bash
docker run -d \
  --name wechat-mp-tools \
  --restart unless-stopped \
  -p 5200:5200 \
  -v $(pwd)/data:/app/data \
  -e TZ=Asia/Shanghai \
  -e BIND_ADDR=0.0.0.0 \
  -e DB_TYPE=sqlite \
  ghcr.io/x554960766/wechat-mp-tools:latest
```

#### 方式 B：Docker Compose 一键构建与启动
```bash
# 1. 克隆代码进入部署目录并一键启动
git clone https://github.com/x554960766/wechat-mp-tools.git
cd wechat-mp-tools/deploy/docker
cp -n .env.example .env && mkdir -p data
docker compose up -d --build
```
启动完成后，在浏览器中访问：`http://<服务器IP>:5200` 即可开始使用。

---

### 2. 🗄️ 数据库配置（SQLite 与 MySQL）

本系统在 Docker 容器化环境下完美支持 **SQLite** 与 **MySQL** 双引擎：

- **方式 1：默认本地 SQLite（推荐，零配置）**
  无需任何额外设置，容器默认使用内置 SQLite 存储，数据库文件直接落在宿主机持久化卷 `./data/wechat_tools.db`，容器重启或重建数据丝毫不丢。

- **方式 2：连接外部/局域网 MySQL（NAS、RDS、自建数据库）**
  在 `deploy/docker/.env` 或运行参数中传入以下环境变量即可自动切换：
  ```ini
  DB_TYPE=mysql
  DB_HOST=192.168.1.100    # MySQL 宿主机或服务 IP
  DB_PORT=3306
  DB_USER=root
  DB_PASSWORD=your_password
  DB_NAME=wechat_tools
  ```

- **方式 3：Docker Compose 一键附带启动 MySQL 8 服务**
  `docker-compose.yaml` 内置了独立的 MySQL 8 服务，执行以下命令即可一键同时拉起应用容器与 MySQL 容器：
  ```bash
  # 启用 with-mysql profile 一键启动应用与 MySQL
  docker compose --profile with-mysql up -d
  ```
  在 `.env` 中指定 `DB_TYPE=mysql`、`DB_HOST=db` 即可直接容器间内网互联。

*安全保障：系统内置多级平滑容灾机制。若 MySQL 服务在启动初期尚未就绪或网络闪断，程序会自动平滑降级至本地 SQLite 守护业务，待 MySQL 恢复后自动重新握手。*

### 3. 镜像形态切换说明

编辑 `deploy/docker/.env` 文件可灵活切换部署形态：

| 形态 | 配置参数 (`.env`) | 特点说明 |
| :--- | :--- | :--- |
| **公众号 + RSS 版**<br>*(默认)* | `DOCKERFILE=deploy/docker/Dockerfile`<br>`IMAGE=wechat-mp-tools-mp:latest` | **镜像小（约 100MB）、内存占用极低**；包含公众号登录、文章拉取、HTML/Markdown 导出、内容过滤与 RSS 服务。 |
| **全功能版** | `DOCKERFILE=deploy/docker/Dockerfile.full`<br>`IMAGE=wechat-mp-tools-full:latest` | 包含所有平台功能（公众号 + 抖音 + 快手 + 小红书 + B站 + 视频号 + 转码工具）。 |
| **PDF 导出支持** | `INSTALL_BROWSERS=1` | 安装 Chromium 内核以启用公众号文章导出为 PDF 功能（体积增大约 1.5GB）。 |

### 4. 数据持久化与常用参数

容器运行仅需持久化挂载 `./data` 目录（存放登录凭据、系统配置、下载历史、RSS 缓存及下载文章）：
- `PORT`：服务端监听端口（默认 `5200`）
- `BIND_ADDR`：绑定地址（如需局域网或公网直接访问可设为 `0.0.0.0`，默认 `127.0.0.1` 配合 Nginx 反向代理）
- `RSS_TOKEN`：可选，为 RSS 订阅源设置访问密钥（如 `?token=your_secret`）
- `RSS_BASE_URL`：可选，反向代理时指定对外公开的 RSS 基准网址
- `DB_TYPE`：数据库引擎类型（`sqlite` 或 `mysql`，默认 `sqlite`）

## 🛠️ 本地源码运行与开发

如果你希望直接运行源码：
